# 演示与提交

视频由本人录制。建议准备一台同 Wi-Fi 的手机或另一台电脑，使用电脑 WLAN 的 IPv4 地址访问，不使用 localhost，也不选 VirtualBox 或 Tailscale 的地址。

## 开始前

1. 确认 MySQL80 正在运行。项目根目录执行 `mvn package`，展示生成的 `target/LibraryWeb2026.war`。
2. 展示 `JAVA_HOME`、`CATALINA_HOME`，执行 `java -version`、`mvn -version`。若终端在变量修改前已打开，请重新打开。
3. 执行 `scripts/Start-Library.ps1 -SkipBuild`，展示 Tomcat 正常启动和本机网页。
4. 执行 `ipconfig`，找到有默认网关的 WLAN IPv4。当前地址可能随网络变化，录制前重新确认。
5. 在另一台设备访问 `http://该IPv4:8080/LibraryWeb2026/`，让视频能看出网址和访问效果。若不通，检查是否同网段、Wi-Fi 是否隔离客户端，以及 Windows 对 Java/TCP 8080 的防火墙规则。

## 功能演示顺序

1. **注册登录**：展示四种角色的额外字段；手机号格式错误、重复姓名或手机号的提示；验证码错误、重置输入和正确登录；首页姓名、角色与各自功能入口。
2. **操作员**：进入图书管理，展示初始列表。添加一本演示图书，库存填 2，保存后出现在第一行；打开副本管理，展示自动生成的 2 个副本；新增一个后库存加 1，删除一个未借副本后库存减 1。
3. **编辑与搜索**：修改书名、作者、类型、出版社、期限、价格。搜索部分书名，清空关键字查询全部。库存、状态没有直接编辑入口。
4. **学生**：搜索刚添加的图书，借阅一次；进入归还图书，展示新记录、副本 ID、借阅时间和应还时间；再次借阅展示可重复操作。操作员此时尝试废弃图书或删除借出副本，展示拒绝提示/禁用按钮。
5. **归还**：学生按列表中的副本归还，记录从未还列表移除；我的借阅中仍有已还历史。全部归还后操作员可废弃，馆藏保留图书但禁止借阅。
6. **教师推荐**：推荐已有书名，展示相关馆藏提示；推荐一本新书，显示待审核。
7. **管理员**：审核新书，填写类型、借阅期限、初始库存，通过后出现在馆藏；另推荐一本并驳回，填写理由；教师账号查看审核结果。
8. **用户查询**：初始不显示用户；输入关键字查询，展示姓名、角色、手机号、专业、创建时间倒序；点击查看展示弹窗，没有增删改入口。
9. **选做查询与统计**：管理员展示借阅关键字、超期、日期范围查询；展示类型和专业统计。学生展示个人全部、未还、日期范围查询。
10. **Gitee**：展示仓库地址和功能提交记录。

备份数据已有早于当前日期的未还记录，超期查询可直接演示。录制演示图书建议使用唯一名字，如“Web作业演示图书”，避免重复推荐命中已有馆藏。

## 最终答案

题目明确要求填写 Gitee 仓库地址，并上传包含 Tomcat 部署和局域网访问的功能演示视频。不要把数据库 root 密码、`config/db.local.properties` 或 `.local/demo-accounts.json` 上传到公开仓库或展示在视频中。

尚未提供仓库地址时，不要填写虚构链接。WAR 已生成不等于已经上传答案区；视频、仓库地址需要在课程平台实际提交。
